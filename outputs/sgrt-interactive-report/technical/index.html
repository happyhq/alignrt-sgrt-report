专利与方法：纹理匹配、歧义拒绝与热稳定
1.04

专利细读：图像块匹配只是入口，热稳定也是测量技术

公开了什么：Vision RT 的 P6 说明书以约 16×16 px 局部块解释对应，并描述随机/准随机纹理、预处理及传感器温度稳定。公开权利要求 1 的核心包括双视角传感器的温度环境；不能把说明书里一句“图像块匹配”当作整个权利要求。 [P6]

为什么这件事关键：微小的传感器/安装几何变化可能改变像素位置，进而通过深度敏感性放大为空间偏差。因此工程比较需要同时看预热、温度变化、图像噪声与几何漂移。这里是由专利披露和几何模型得到的工程分析，尚未测量本机样件。

证据落点说明书实施例 ≠ 当前产品配置。16×16 不应写成 AlignRT 各版本的固定窗口；光源波段、温控方案、匹配器和滤波器仍需逐版本资料确认。
1.05

同一片散斑怎样找：极线约束、评分和歧义拒绝

通用匹配模型 · 本文解释d* = argmind C(L(x,y), R(x−d,y))ZNCC = Σ(L−L̄)(R−R̄) / √[Σ(L−L̄)² Σ(R−R̄)²]

先用标定和极线校正把二维搜索压到对应扫描线附近，再用窗口内亮暗排列计算匹配代价。上式用 ZNCC 展示“比较结构”的思想；本文没有证据认定 AlignRT 使用 ZNCC、SGM 或某个学习模型。无纹理时分母可能接近零，重复纹理可能出现多个相似峰；最优分数本身还不够。

左右一致性、搜索边界、饱和与遮挡检查用于拒绝不可信点。亚像素拟合可以细化峰的位置，但不会自动消除错配。P6 只为局部块与纹理提供公开线索；这里的评分和拒绝链是通用教学模型及本地 D06 设计。 [P6][D1]

从像素到XYZ：公式成立的前提
uL−cxL = fX/ZuR−cxR = f(X−B)/Zdeff = (uL−cxL)−(uR−cxR) = fB/ZX = (uL−cxL)Z/f； Y = (vL−cy)Z/fy

只在已去畸变、水平校正且投影模型适配时使用；主点未对齐需使用有效视差。真实一般布局通过完整投影矩阵或Q处理。深度误差公式仅传播小视差随机误差，未含标定偏差与相关误差。 [D1]

把推导与本节的实际评分曲线对起来

上方实验从Canvas图像中取16×16像素窗口，逐一计算24—72px这49个候选的ZNCC。随机散斑的生成真值是48px；重复图案每16px出现类似排列，约32、48、64px都可能给出高分，亮度噪声还会使峰值略有差异。

因此，不用“某个候选分数高”代替唯一性判断。无纹理时相关系数没有定义；重复纹理有歧义时不接受深度。只有本节接受的像素对应，才会由按钮送入下一节的同参数三角测量。窗口与评分均是教学实现，不是厂商匹配器披露。

由对应像素还原深度 Z = fB / d

为什么两个横坐标一减，就能求深度？

uL − cₓ = f · X / Z
uR − cₓ = f · (X − B) / Z
d = uL − uR = fB / Z

右相机横向移动了 B，同一点相对它的横坐标变为 X − B。两式相减消去 X，再整理得到 Z = fB/d。B 是两相机光心间距，X、Z 以左相机为原点。[D1]

进一步用 X = (uL − cₓ)Z/f、Y = (vL − cᵧ)Z/f 还原完整三维点，对大量有效对应点重复计算，就得到局部体表点云。

公式使用去畸变、极线校正后，同焦距且主点对齐的理想模型。标定确定焦距、主点、畸变以及两相机相对位姿；实际重建使用完整标定几何。[D3]

为什么越远，深度越难精确测量？

距离越远，视差越小；相同的视差误差会对应更大的深度误差。固定距离时，增大基线会增大视差。

|ΔZ| ≈ Z² / (fB) · |Δd|

假设视差误差 |Δd| = 0.1 px，上方参数对应这一近似深度误差。

本数值由理想模型求导得到，仅传播视差误差；不代表 AlignRT 精度。匹配遮挡、同步与标定误差还会影响实际结果。

    论文与专利：标定误差为何需要独立空间验证
    2.04

    从 Zhang 平面标定到治疗室坐标，中间缺了哪一步？

    Zhang 的原始工作提供多姿态平面目标估计相机模型的路线。P5 则把相机内参、机头相对方向、治疗室焦点关系以及模型生成连接起来。两者分别回答“如何成像”和“相机在房间中的位置怎样定义”。 [A1][P5]

    通用一阶分析，不是设备实测δZ/Z ≈ δf/f + δB/B − δd/dB估计偏大1%，其余量固定 ⇒ Z偏大1%；Z=2000mm时约偏大20mm

    标定靶尺度若存在共同偏差，拟合仍可能很整齐；多台相机也可能彼此一致却整体偏离外部基准。需要把拟合残差、留出空间误差和任务空间误差分别报告。P5 中对治疗室焦点/激光的登记描述，不能直接当成已独立确认辐射等中心。 [G1]

    工程建议分别用独立长度验证尺度、用不同深度/边缘位置检验几何、用预热/重装试验检查漂移；R0 仍只到已登记的台架测量空间。

    专利反例：为什么换视角可能制造假运动
    3.03

    多视角为什么有时会“凭空测出运动”？

    P1 说明书指出：相机视线被设备遮挡后，剩余视角重建的表面可能与之前模型存在差异，模型差异可能被解释为患者移动。因而多视角的技术难点还包括“观测集合改变时，偏差估计是否改变”。 [P1]

    通用坐标表达pC(k) = TC←k · pk；保留source_view与采集时刻

    坐标合并需要每组机头到共同坐标的变换；可靠融合还取决于同步、入射角、遮挡边缘和局部噪声。公开资料未给出 AlignRT 当前版本的全部融合权重，本文不把简单平均描述成其实现。可在静止已知模体上切换遮挡，检查真值不动时读数是否产生系统偏差。

    质控与配准：验证设备，再估计体表位姿

    质控把系统读数与独立已知真值比较；配准寻找当前体表与参考体表之间的空间变换。[G1]

    把“位置偏了”和“位移量错了”分开检查

    同一零点偏移可出现在两个位置。即使两次读数相减仍是 10 mm，绝对位置也可能存在误差。

    读数 m(x) = (1 + ε/100) x + b
    −3 mm+3 mm
    −10%+10%

    这里显示误差，不设置临床合格阈值；按钮只改变模拟读数模型。

    复测与稳定性

    比较重复测量与不同时刻的读数，观察重复性和漂移。

    空间基准

    验证定位范围、不同几何状态，以及光学、成像和辐射基准的一致性。

    动态与接口

    已知运动、时间响应、门控和数据传递也属于需验证的链路。[G1]

    移动轮廓，观察求出的位姿与残差

    旋钮给出用于生成当前轮廓的已知位姿；估计器再用参考点 p 与当前点 q 求 R、t，使 ROI 内点对距离的平方和最小。

    q ≈ R p + t
    对齐到参考：q′ = Rᵀ(q − t)

    位姿估计方向：参考 → 当前。这里的平移与旋转是截面坐标中的示例，非治疗床指令。

    参考从哪里来？

    计划 CT 外轮廓，或按工作流程采集的光学参考表面。[G1]

    实际怎样找对应？

    通用 ICP 类方法交替建立点对应、求刚性变换并更新配对。本例只展示点对已知时的求解。[D2]

    怎样理解残差？

    ROI 的形变、遮挡与几何特征会影响结果；平坦或对称区域可能缺少唯一定位信息。AlignRT 的具体配准实现为专有算法。[G1]

    质控验证设备测量 → 当前体表重建与融合 → ROI 配准 → 位姿偏差 → 运动监测与接口响应。质控误差描述设备表现，配准位姿描述当前体表相对参考的关系。

    ROI：测到了表面，为什么仍可能判断不出滑动？

    ROI 是参与配准的体表区域；可观测性指这些几何信息是否足以区分不同运动。[3] §4.2

    换形状、换方向，再找最低点

    试一试：选择“单向隆起”，把测试方向从 x 换成 y。沿隆起延伸方向滑动，形状可以保持相同。

    几何有起伏 → 位移改变观测
    某方向几何不变 → 该方向存在歧义

    散斑帮助每帧重建三维；它不是固定粘在皮肤上的标记，不能直接补足无特征表面的跨帧几何约束。

    大小不是唯一指标

    关键是 ROI 是否含有能区分运动方向的几何特征；扩大平面仍可能保留歧义。

    形变与遮挡也重要

    区域需要适合监测任务，并有稳定可见的表面。纳入独立运动的部位可能改变配准结果。

    还有时间上的取舍

    ROI 大小可影响处理负担与时间分辨率，具体表现需按设备与工作流程验证。[G1]

    三维 6DoF：三个平移、三个旋转，还要说明坐标和中心

    保持角度不变，换一个旋转中心

    相同角度，不同点位移不同

    旋转中心决定旋转的作用位置；离旋转轴越远的点，通常移动越多。变换中的平移分量也随中心表达而改变。

    11

    门控时延：已经越界，为什么束流还可能尚未停止？

    帧率决定采样间隔，端到端时延还包括处理、通信与治疗机响应；需要验证完整链路。[3] §3.3.2

    分别改变帧率和每一级延迟

    Δt = 等待下一帧 + 处理 + 接口 + 停束响应
    继续移动 Δx = 速度 v × Δt

    提高帧率只缩短其中一段

    即使等待下一帧接近零，后续处理、接口和治疗机响应仍可能需要时间；平均等待也不等于最坏等待。

    信号改变与束流改变分开看

    完成越界判断、发送暂停请求、设备实际停束是不同事件；继续移动距离不是剂量误差的直接计算。

    重新入窗之后呢？

    还需有效测量和相应流程授权。本例不推定自动恢复规则，也不模拟厂商滤波、迟滞或联锁；实际逻辑按版本和接口验证。

    三维配准：怎样从两份点云求出未知的 6DoF？

    第 10 节施加已知变换；这里实际计算最近邻对应与三维刚性最小二乘增量。采用通用点到点 ICP 教学算法，不代表 AlignRT 专有实现。[D2] [V1]

    给定粗定位初值 T寻找最近点剔除超距对应求刚性增量 ΔTT ← ΔT · T，重复

    先从接近的初值迭代，再试较差初值

    估计方向：当前 → 参考；下方按 R = Rz Ry Rx 分解，仅用于读数。

    生成运动为参考 → 当前：平移 (4, −3, 2) mm，旋转 (2, −3, 4)°。其逆变换的平移与角度需按顺序计算，不能逐项照抄负号。

    每次“求增量”具体求什么？

    固定本轮对应，最小化 Σ‖ΔR · pᵢ + Δt − qᵢ‖²，约束 ΔR 为旋转且不允许缩放。此例用 Horn 四元数法计算最优旋转，再由质心差求平移。下一轮重新找对应。[A2]

    初值为何重要？

    最近点未必是同一个物理位置。错误对应也可能形成稳定解；“变化很小”只表示当前迭代停止变化。

    残差与覆盖一起看

    只保留少数容易拟合的点，RMS 也可能很小。因此同时显示接受数量；没有可用点对时不显示零误差。

    求出了刚性变换，接下来呢？

    还要检查表面是否发生形变。六个刚性参数不能解释所有局部变化。进入第 13 节 →

    论文与推导：最近邻、Horn求解与几何退化
    4.04

    配准不是把图形挪近：对应未知与刚性求解是两个问题

    固定尺度的通用刚性问题 · 当前 → 参考minR,t Σ wᵢ ‖Rpᵢ+t−qc(i)‖²，RᵀR=I，det(R)=+1点到面：min Σ wᵢ [nᵢᵀ(Rpᵢ+t−qc(i))]²

    对应已知：Horn 的绝对定向工作给出最小二乘旋转求解的经典路线；本报告固定尺度为1，平移由质心关系得到。对应未知：ICP交替更新最近点配对和刚性变换，Besl–McKay 是经典出处。 [A2][A3][D2]

    上述算法谱系解释“可以怎样求解”，不等于 AlignRT 的源代码。Vision RT 官方将其表面配准明确称为专有算法；P1 说明书提及 Procrustes 型比较，也不能据此断言当前全部版本就是原版 ICP。 [V1][P1]

    为什么平面会产生“低残差、错位姿”？

    对理想平面 z=0，法向 n=(0,0,1)。把点沿 x 方向移动 a，点到面残差仍是0；平面内两个平移与绕法向旋转均缺少足够约束。有限边界可增加信息，但遮挡会再改变这些约束。

    rᵢ ≈ nᵢᵀδt + (pᵢ×nᵢ)ᵀδω； H = Σ wᵢ JᵢᵀJᵢ

    这是本文对点到面目标的小角度线性化：H存在弱方向时，小残差不能保证该方向的位姿稳定。该矩阵用于说明几何可观测性，不作为跨单位的通用阈值；本报告没有新增通过线。

    验证落点分别报告位姿误差、有效对应数量、残差分布和失败率；逐轴平移/旋转、平面、对称、局部形变和较差初值都应进入测试矩阵。
    输出：相对所选参考与ROI的刚性变换。六个数字去掉后，哪里还剩局部形变？ ↓
    13

    形变与残差：六个数字拟合之后，还剩下什么？

    先求整体刚性对齐，再看局部偏差的空间分布；局部隆起、凹陷与整体移动需要分别理解。[3] §4.7.2

    让局部形变进入或离开拟合 ROI

    整体刚性变换 → 六个参数
    局部形变 → 随位置变化的残差分布

    试一试：保留局部隆起，将 ROI 改为“仅形变中心附近”。局部残差可能更小，但拟合会把一部分形变解释成整个表面的移动或转动。

    改变 ROI 会改变“最佳整体位姿”的定义；残差图应结合解剖、参考状态和影像证据解释。

    点对 RMS 与颜色值不同

    RMS 使用三维点对距离；颜色只显示法向分量。切向滑动可能在法向图中不明显。

    低残差需要说明范围

    “小 ROI 内拟合很好”不能证明 ROI 外也对齐；局部形变、姿态改变和参考差异都可能留下残差。

    形变显示不等于形变校正

    展示表面差异，并不意味着治疗床能把所有局部差异一起消除；床的刚性运动只有有限自由度。

    14

    遮挡与有效性：没有可信的新测量，不能读作“零运动”

    覆盖率、几何约束和数据新鲜度共同影响可用性；遮挡也可能改变剩余 ROI 所提供的方向信息。[3] §3.4.4、4.7

    先制造丢失，再逐帧重新获取

    本例判据：覆盖率 ≥55%、几何约束比 ≥0.001、数据更新有效；丢失后连续 3 个合格教学帧才恢复。全部阈值和帧数为演示设定，非 AlignRT 规则。

    “几何约束比”怎样计算？

    用每个可见点的位置 p 与法向 n 构建小运动的点到面雅可比 J = [nᵀ, (p × n)ᵀ/L]，L = 100 mm 仅用于统一量纲。计算 ΣJᵀJ 的最小与最大特征值之比。平面的某些平移和旋转缺少约束，即使点数很多，比值仍可为零。这不是置信概率或临床合格指标。

    单个 POD 被挡不一定丢失

    其他视角可能仍提供足够表面；需要看剩余覆盖和几何，而不是只数在线 POD。

    上次读数不是当前测量

    新数据缺失时，保留在屏幕上的旧位置不能当作刚取得的有效位置。有效性与运动大小是两个问题。

    重新看到，也要重新判断

    本例用 3 帧展示重新获取状态；实际恢复判据及其与束流的关系，取决于系统版本、接口与流程。

    研究反例：颜色、角度与遮挡如何影响观测
    5.03

    反证比宣传更有价值：静止头模为什么出现偏移？

    Covington 等用同形四种颜色头模，改变床角和相机遮挡。指定系统/版本的部分组合出现无法定位或最高约 5mm 的偏移；回到初始几何后的读数用于检查模体是否发生了实际移动。 [E2]

    这说明什么：同一物体的反射、视角与覆盖变化可以改变测量；必须验证颜色×遮挡×角度的组合。不能外推什么：研究列出AlignRT 6.3.1（第4/5代相机）及IDENTIFY 2.3/3.0，但结果A–D做了匿名化，本文不把某个最大偏移归到指定厂商。3D打印材料不等同真实皮肤，不能代表全部后续版本；IDENTIFY由产品评价协议提供。

    由证据导出的工程建议失败记录既要包含“没有结果”，也要包含“有数值但错误接受”；全序号分母保留有效、无效、迟到和丢失，不能只计算成功帧RMSE。

    体表与内部：相同的外形观测，能否唯一确定内部位置？

    相机测量可见体表；它与靶区或器官的关联取决于解剖和治疗任务。内部影像提供另一类定位证据。[3] §4.6.1、4.7.1

    体表连续监测：相对参考的外部运动
    内部影像核实：成像时刻的内部位置

    一次内部影像是一个时刻的证据；后续表面监测依赖已建立的关联与适用条件。更换表面参考，也不会自动验证内部位置。

    DIBH 不是只追一个高度

    不同呼吸模式、姿态或局部形变，可能影响体表与内部的对应；单一垂直读数不能表达完整呼吸姿态。

    有些任务的关联更直接
