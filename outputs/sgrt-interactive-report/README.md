# AlignRT 与 SGRT 全面入门 · HTML5 交互式专题报告

## 使用

在线阅读：<https://happyhq.github.io/alignrt-sgrt-report/>。主分支更新后由 GitHub Actions 检查并自动发布，部署进度可在仓库 Actions 中查看。

直接打开 `index.html` 即可离线阅读。请保留整个目录，尤其是 `assets/`，不要只复制 HTML 文件。无需安装、构建、账号、密钥或服务器。

网页提供阅读进度、章节目录、原文定位、图片放大及缩放、章节正文复制、延迟教学演算、五题自测及打印。手机表格支持左右滑动。关闭 JavaScript 后，正文、普通锚点与原生折叠答案仍能阅读。

## 内容与设计

底稿为本工作区《AlignRT与SGRT零基础入门_学习版.pptx》，共 29 页。另两份入门 PPT 同为 29 页，采用学习版作为统一来源。参考网页仅用于研究米白纸面、中文衬线标题、细线分隔、边栏目录与杂志式双栏的阅读语言，未使用其正文或插图。

正文重组为七章：放疗定位、光学原理、临床工作流、工程评价、产品研发、学习巩固、结语与来源。所有原始页面文字、表格与备注均可在网页底部逐页核对；原始资料检索日期保持为 2026-11-02，初版编排日期为 2026-11-03，阅读版式修订于 2026-11-04。来源记录中的数值与引文未作为“当前重新核实”的研究结论发布。

PPT 的厂家照片与截图改为 SVG 概念图，原图出处保留在逐页备注。本次修订采用用户提供的 `exploded(1).html` 工程结构素材，整理系统部署、相机单元、体表网格和校准结构，统一编号、引线、线宽及纸面色；其余四图保持原文事实并统一线型。9 组原素材组成独立交互式结构图集，保留拆解、装配、部件隔离与参数查看功能。

材料中的内部构造、参数和选配件描述均属于参考材料的表达，不新增为原 PPT 的事实、产品配置声明或独立验证结论。教学图不代表实际机房尺寸、设备性能、临床阈值或患者数据。延迟演算保持 PPT 中的匀速模型，默认例题为 10 mm/s × 0.10 s = 1 mm。

## 架构与发布

网站使用静态 HTML、原生 CSS 和原生 JavaScript。没有框架、包管理、远程字体、图片热链、API、数据采集或分析脚本。阅读状态和自测状态只在本次页面打开期间存在。

将这个目录中的全部文件上传到任意支持静态文件的托管空间，例如既有网站目录、GitHub Pages、Nginx 或组织内部静态服务器。将发布根目录指向本目录，首页文件为 `index.html`，无需构建命令。资源使用相对路径，可放在站点子目录。部署后验证 `/assets/` 路径可访问即可。

本地若需要通过 HTTP 演示，可在此目录执行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8765/`。这只是可选预览方式，离线阅读不需要启动它。

## 打印

点击页面的“打印 / PDF”，选 A4、纵向、100% 缩放，并启用背景图形。打印样式移除导航、复制按钮和原文档案，自动展开五题答案，并在关闭打印窗口后恢复阅读状态。原文存档可另行使用 `report.md` 或 `source.json`。

附带 PDF 为 Microsoft Edge / Chromium 导出的 20 页 A4 样张，含页脚和页码。不同浏览器、系统字体与打印缩放可能产生少量分页差异。PDF 是静态阅读副本，交互以 HTML 页面为准。
