05 / MEASURE → CONTROL

05从测量到
反馈与门控

体表偏差怎样经过判定、接口和延迟，变成患者看得见的反馈或允许出束的信号？为什么“屏幕上变了颜色”不等于“束流已经停止”？

本章工程结论反馈颜色、运动许可和束流停止不是同一个事件；完整响应链必须端到端测量。

把“反馈”拆成一条链

测量值先经过目标带和有效性判断，再变成患者反馈或门控请求；请求还要经过接口传输、治疗机响应和实际停束。每一段都可能引入时延，也可能因为状态不清楚而需要降级或暂停。

帧率描述相机多久采一帧，端到端时延描述从表面变化到最终动作的完整时间。两者不能互相替代；设备接口是否已获授权、是否失效安全，也必须在真实系统上验证。

不要合并三个词显示反馈 · 运动许可 · 停束完成。它们是三个不同层级的事件。

帧率、处理耗时、接口和设备响应不是同一个指标；“停束请求”也不等于“束流已经停止”。

Fact · 接口与时延

公开指南关注 motion management 与 QA；研究文献提示帧率、日志时间和真实响应链不能混为一谈。

Inference · 系统设计

端到端时延要按链路测量；任何模拟接口都不能被读成真实出束授权。

Assumption · 反馈规则

本页目标带、颜色和教学速度均为合成参数，不代表任何厂商或临床协议。

本章能回答什么？

能解释测量、判定、反馈、接口和停束的分层关系；能说明帧率为什么不能替代端到端时延。不能从本页推出真实设备控制、停束安全或临床工作流已经获批。
