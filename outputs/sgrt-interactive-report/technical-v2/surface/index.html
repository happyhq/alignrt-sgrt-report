01从体表到
三维测量

一帧图像怎样变成可解释的三维表面？先分清纹理、对应、三角测量和“这张表面是否可信”是四个不同问题。

本章工程结论有纹理、有对应、有标定，才有一个可用的三维点；某个点被重建，不等于整张体表都可信。

一条从光子到坐标的链路

主动双目系统先用投影器补充可辨识纹理，再由两台固定相机在同一时刻观察同一片体表。两幅图像中的同一表面点在横坐标上产生视差，结合已标定的焦距和基线，才能恢复深度。

这条链路里，任何一个环节都不能用“后面还有算法”替代：没有纹理会产生匹配歧义，匹配错了会得到错误的视差，标定不准会把像素误差放大成空间误差。

实验 1.1 · 旧 01 光学采集：一组相机怎样看见体表？ system

典型主动双目单元由两台相机和中央投影器组成：投影器增加纹理，相机从不同方向观察。可见性不是“有相机就有数据”，机架、治疗床、固定装置和患者体位都可能挡住某一片表面。

Fact · 公开机制

主动双目使用投影纹理、双视角图像和三角测量。厂商公开资料能支持这条技术路线，但不公开完整匹配器。

Inference · 工程判断

匹配唯一性、标定几何和遮挡会共同影响三维点；单个高分不能证明整张表面有效。

Assumption · 教学条件

本页 f、B、窗口和阈值均为固定教学参数；用于理解关系，不用于设备选型或临床比较。

本章能回答什么？

能解释一个三维点是怎样从纹理、对应和视差得到的；能说明为什么无纹理、重复纹理和错配会让深度失效。不能据此声称任何具体设备的精度、速度或临床适用性。
