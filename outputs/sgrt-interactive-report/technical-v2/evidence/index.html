06 / SURFACE → INTERNAL

06从服务应用到
证据边界

体表测量能支持哪些结论，哪些还需要内部影像和独立验证？一个漂亮的外部轮廓，为什么不能自动代表体内靶区位置？

本章工程结论体表测量不等于体内靶区位置；服务能力需要场景、真值、接口和临床流程的分别验证。

把“相关”与“替代”分开

体表是可见、连续、容易获得的信息；内部靶区位置通常需要影像或其他独立证据。两者可能相关，但相关不等于可以互相替代。尤其在呼吸、形变、不同部位和不同治疗任务中，表面变化与内部运动的关系需要单独建立和验证。

因此，本章不提供新的临床结论，而是把证据分层：哪些是公开资料支持的事实，哪些是从几何和流程得到的工程推断，哪些只是下一步要验证的工作假设。

阅读目标能说出“体表测量能回答什么、不能回答什么”，并知道下一步该要哪种证据，而不是只记一个产品名称。

APPLICATION / 待场景验证

SERVICE服务应用方向

把体表测量转化为可解释、可复核、可追溯的信息。以下只是应用研究与验证问题，不是已批准的服务能力。

服务环节拟研究的 SGRT 支撑需要回答的验证问题
治疗准备 / 摆位辅助利用参考体表、ROI 与体位差异提示，研究怎样辅助复现已确认体位。参考如何建立？坐标是否一致？怎样结合独立影像核实？
治疗过程 / 体表运动监测研究连续呈现体表偏差与测量有效性，识别需要复核的变化。适用于哪些部位？遮挡后如何恢复？数据是否新鲜？完整响应链多长？
质量管理 / 记录与追溯研究串联标定、QA、测量、异常和回放资料，支持服务团队复盘。记录是否完整？版本能否追溯？是否有独立真值与试验记录？

当前验证起点R0 仍为单组双目、模体台架、质量/回放/QA 与模拟接口。上述方向需逐项验证后才能形成服务能力；患者应用、真实门控和设备控制另需授权与联合验证。

Fact · 证据分层

公开指南、专利、论文和监管文件分别支持不同的陈述；全文、摘要和厂商页的证据强度不同。

Inference · 系统边界

体外测量可以连续观察外部形状；体内靶区需要独立影像或与表面建立并验证的关系。

Assumption · 应用方向

中玖闪光的服务应用仍属于待场景验证的研究方向，不是当前 R0 已实现能力。
