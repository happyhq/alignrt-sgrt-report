# 专题报告的设计分析与改进

对照对象：<https://czm15053.github.io/ai-coding-less-waste/>。本次在相同的 1440×1000 桌面视口与 390×844 手机视口检查参考站和报告，改进现有专题的阅读体验。参考站的部分正文配图在截图时未加载，因此不对那些图的最终视觉表现作判断。

## 结论

原版已有米白背景、细线、章节编号及完整交互，但仍带有逐页讲义的排列方式。主要问题是标题气势不足、解释文字层级过低、列表节奏重复，以及复杂技术图的展示面积不足。改版围绕中文专题的阅读体验，不移植参考站的内容与插图。

| 阅读环节 | 原版观察与影响 | 本次改进 |
|---|---|---|
| 1. 首屏理解 | 桌面主标题 54px，参考站主标题 82px；原版细衬线字体与大量小字号元信息削弱标题层级 | 桌面主标题 72px、中文粗体，手机自适应；右侧以“观察、比较、确认”组织导读，原工程结构图保留为源资产 |
| 2. 章节导读 | 章节头与正文之间层次接近，较难快速区分七个主题 | 使用克制的灰绿、灰蓝和暖灰章节底色，保留编号、导读及核心判断 |
| 3. 连续阅读 | 多数解释性段落放在 13px 灰色“补充理解”中，关键说明易被略过 | 桌面解释文字调整为 15.5px，手机 15px，并提升对比度；选取已有解释前置为导读，不增加事实 |
| 4. 图文阅读 | 相机拆解、表面网格与校准图压在约半栏宽度中，图内标签难读 | 三类复杂图采用通栏展示；系统结构图放回设备部署正文。简单流程继续双栏，形成疏密变化 |
| 5. 长文导航 | 1440px 桌面目录隐藏，阅读到中段后缺少就近导航 | 1440px 及以上保留边栏目录，中间宽度与手机使用常驻页头目录；当前章节和阅读进度随正文更新 |
| 6. 来源核对 | 原文与正文堆叠，正文样式与档案样式区别不足 | 档案继续按需展开，引用保持可定位。阅读进度以七章正文结束位置计算，档案不拉长正文阅读进度 |

## 实施边界

仍使用语义化 HTML、原生 CSS 和 JavaScript。新增 `assets/editorial.css` 组织屏幕阅读样式，既有 `assets/styles.css` 继续承担基础样式与 A4 打印基础。章节锚点、图片放大、复制、自测和离线使用保留。

`source.json` 与 `report.md` 保持逐字节不变。重排使用原来已有的说明段落，工程图沿用用户提供的结构素材，不增加临床收益、设备精度或治疗阈值。材料中的概念结构继续明确标注。

使用真实浏览器引擎检查标题、正文、章节和复杂图；检查桌面、平板和手机视口，验证目录展开/跳转、图片缩放、自测和演算。完整性检查不等同于全量无障碍认证，手机视口模拟不替代真机测试。源文件与引用按原资料保留，不以本次视觉改版冒充医疗专业复核。
