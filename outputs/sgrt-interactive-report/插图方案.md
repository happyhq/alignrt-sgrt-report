# AlignRT 与 SGRT 专题报告插图方案

## 设计原则

采用米白底、炭黑轮廓、砖红编号、灰绿辅助色。所有正文图为独立 SVG 文件，中文标签，提供替代文本、图注及原 PPT 页码。不沿用参考网页的文案或插图，不把示意图呈现为设备照片、患者影像或实测数据。

本次依据用户提供的 `exploded(1).html` 修订：系统、相机、表面网格和校准图直接使用所供工程线稿的几何结构，重排编号引线与中文标签，删除不适合正文的细节声明。其余四图统一为细线技术图风格。原素材的九组图另外保留为可交互图集，作为概念结构参考，不增加到已核实的产品事实中。

## 原始插图处理

PPT 中的厂家治疗室照片、立体重建图和偏差界面改为独立 SVG 资产，其中本次四幅结构图采用用户所供工程线稿整理。PPT 原图的出处仍完整保留在逐页来源记录中。网页不依赖厂商热链。

## 图表与交互

设备分工、SGRT/影像比较、场景、状态、异常、性能、接口、厂商、角色、误区、缩写和学习计划，均采用原生 HTML 表格并保留原始文字。只对 PPT 已给出的几何教学关系提供参数演算，不添加性能排名、临床阈值、市场数据或统计图。
