放疗定位：SGRT 看什么

先理解治疗计划、每日摆位与治疗中运动，再区分体表与体内影像各自提供的信息。

本章判断

体表稳定不能单独证明体内靶区稳定。

1.01

放疗的核心：把计划剂量送到正确位置

补充理解

把计划想成在特定姿势下制定的照射安排。患者姿势或内部解剖发生变化后，原计划与当天身体的对应关系可能改变。SGRT关注可见体表的位置变化。这里不介绍任何个人治疗方案。

照射肿瘤，同时尽量保护周围正常组织

治疗计划
根据影像确定靶区、正常组织和照射方案。
分次治疗
许多方案分多次完成，每次都要重新摆位。
位置变化
每天体位不同，治疗时也可能出现呼吸或不自主运动。

要点SGRT 参与位置与运动管理，治疗剂量仍由治疗系统按计划递送

2.05

ROI：选择哪些体表来计算

补充理解

ROI不是固定的“框大一点”或“框小一点”。头面部监测通常应避免把易独立运动的部位当作稳定基准。乳腺场景中，身体整体姿态和局部胸壁状态都需要评估。具体边界按专业人员批准的协议设置。

ROI = Region of Interest，感兴趣区域

选得太少
可用形状特征不足，局部遮挡影响可能更大。
选得太杂
无关部位和独立运动可能干扰配准结果。
按任务选择
摆位看整体姿态，局部监测关注适当的稳定区域。

要点ROI 的好坏取决于临床任务、表面特征和可见性

2.06

参考体表有两种常见来源

补充理解

参考的选择随病种和流程不同。CT参考适于表达计划时的体位，相机参考适于表达已经验证的治疗位姿。更新参考须受控，不能为了让偏差数字变小而随意重置。深吸气屏气和自由呼吸状态也需要区分。

来源便于理解的含义需要关注
CT 导出体表从计划 CT 提取外轮廓层厚、分割阈值和伪影会影响表面
相机采集体表记录某次已确认的体位采集时若位置有误，会把误差存为基准

常见监测做法：内部影像复核后，采集相机参考体表

要点每份参考都应能追溯到患者、疗程、用途和确认状态

3.01

DIBH：在可重复的屏气状态下治疗

补充理解

DIBH不是憋气越深越好。教学上可以分成自由呼吸摆位、练习屏气、确认屏气位置、允许出束、离开范围后暂停等环节。患者是否适合以及具体屏气安排由治疗团队决定。本页不提供通用屏气时长或阈值。

Deep Inspiration Breath Hold = 深吸气屏气

临床目的
部分左侧乳腺患者可通过深吸气改变心脏与照射区的几何关系。
SGRT 作用
观察体表是否进入并维持在已定义的屏气范围。
患者参与
通过视觉或声音反馈练习可重复的屏气状态。

要点临床收益要通过该患者的计划与影像评估，不能由曲线单独判断

3.02

SRS 与 SBRT 的应用关注点

补充理解

SRS常用于颅内立体定向治疗语境，SRT是立体定向放射治疗更广的说法。SBRT用于体部特定适应证。SGRT可辅助这些流程，但开面膜、无框架或特定自动功能均取决于实际设备、配置和经验证的临床方案。

场景SGRT 可提供什么额外关注
颅内 SRS / SRT
立体定向放射治疗		辅助摆位与治疗中体表监测固定方式、床旋转、离中心目标
体部 SBRT
体部立体定向放射治疗		姿态与呼吸运动相关信息体表与内部靶区的相关性

要点高精度治疗更依赖完整验证，不能直接照搬另一病种的协议

3.04

门控与停束：测量怎样影响治疗

补充理解

Beam hold表示暂停治疗束；gating表示按运动等条件控制允许出束窗口。具体逻辑、失效安全、恢复出束和权限由已验证系统共同决定。自动停束功能不能假定为需要人工确认后才执行。恢复出束的条件也不等同于停束触发条件。

系统状态信息含义应明确的处置
有效且满足条件测量可信，偏差处于批准范围仍须满足治疗机的其他出束条件
有效但超出条件测量可信，运动超过设定范围报警或经授权接口触发停束
无效或信号丢失遮挡、丢帧或接口故障导致无法判断按风险设计进入安全状态

要点无有效数据不能显示为“偏差为零”或默认为可以治疗

28

01 产品与类别

AlignRT 是 Vision RT 的产品，SGRT 是技术类别。

02 需要复核

体表与内部靶区的关联并不总成立，按协议进行影像验证。

03 能力分开

显示偏差、输出建议和执行床运动需要分别确认。

显示测量不可用，并按验证过的安全逻辑处置。

05 查完整证据

问场景、真值、统计方法、动态延迟、遮挡和临床证据。
